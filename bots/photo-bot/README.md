# Фото-бот для статей

Пересылаете боту сообщения с фотографиями и подписями («это в статью про утильсбор»), пишете `/done` — бот присылает архив:

```
photos-2026-10-29-12-00.zip
├── CLAUDE.md          — задание и разметка для Claude: какие фото к какой статье
├── manifest.json      — то же в JSON
└── photos/
    ├── 01-customs-and-recycling-fee-2026/01.jpg
    └── 02-japan-auction-sheet/02.jpg
```

Архив закидываете в Cowork вместе с проектом — Claude заменит фотографии в статьях.

- Фото без подписи берёт подпись своего альбома, иначе — последнего сообщения/подписи.
- Можно переслать отдельный текст — он станет подписью для следующих фото.
- Бот угадывает статью по словам подписи и списку статей из CMS; в `CLAUDE.md` это помечено как догадка.
- `/list` — что собрано, `/reset` — начать заново.
- Отвечает только владельцу: ID из `PHOTO_BOT_ALLOWED_IDS`, а если он пуст — тому, кто первым написал боту.

## Запуск на сервере

Один раз от root (токен из @BotFather, второй аргумент — ваш Telegram ID, можно не указывать):

```bash
bash bots/photo-bot/server-setup.sh <токен> [telegram_id]
```

Файл бота приезжает на сервер вместе с деплоем сайта (`release/photo-bot/bot.mjs`) и перезапускается вместе с `rangauto.service`.
Логи: `journalctl -u rangauto-photo-bot -f`.

## Запуск где угодно

Нужен только Node 22, зависимостей нет:

```bash
PHOTO_BOT_TOKEN=<токен> CMS_URL=https://rangauto.ru/cms node bots/photo-bot/bot.mjs
```
